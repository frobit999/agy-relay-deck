# Contributing

Small, focused pull requests are welcome.

1. Fork the repository and create a branch.
2. Keep the dashboard dependency-free unless a new dependency is clearly necessary.
3. Never commit real account files, tokens, conversation databases, annotations, brain folders, or absolute personal paths.
4. Run `npm test` before opening a pull request.
5. Explain any changes to the transplant table allowlist or binding-preservation rules in detail.

When reporting a bug, include the macOS, Node.js, Python, `agy`, and Antigravity Tools versions. Redact emails, tokens, prompts, conversation titles, IDs, and filesystem paths.
